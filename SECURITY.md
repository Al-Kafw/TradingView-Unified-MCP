# Security policy

See [the current source audit](docs/SECURITY.md) for the reviewed boundaries, fixes, tests, and limitations, and [the README](README.md#data-handling-and-security-boundaries) for data flows and configuration.

Use a trusted MCP client, a dedicated extension-free browser profile, and a loopback debugger. Requested source, screenshots, alert content, and exports can contain private information. The server cannot control how your MCP client or its model provider handles tool results.

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/daviddme/TradingView-Unified-MCP/security/advisories/new) when it is enabled. If that channel is unavailable, open an issue requesting a private contact route without including exploit details, credentials, cookies, private scripts, or account data. Do not post working session credentials in a public issue.

Only the latest published source revision is maintained. No independent security certification is claimed.
